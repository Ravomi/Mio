原语核心与实时控制

有界检索与唯一匹配

内置 read、write、edit、grep、find、ls 与 bash 七个独立一级工具。分页读取限制单次 64 KiB 输出，Thompson NFA 正则检索跳过构建产物与符号链接，edit 在零匹配或多处匹配时直接拒绝写入并返回 Unified Diff。

工具权限策略 (--tools / --approve) 7 tools active

四路子代理与目录锁

开启 --subagents 后，主代理可并发委派最多四路独立子会话。探索任务默认开启 read_only: true，在工具注册与执行双层硬性拦截写入与 Shell；重叠工作目录自动执行只读共享、写入独占互斥锁。

按需上下文与思考档位

基础系统提示词仅 84 字（约 180 tokens）。自动按目录层级加载 AGENTS.md 与 .mio/SYSTEM.md，项目 Skills 默认只注入摘要、按需读取正文。支持一键导入本机 Antigravity OAuth 授权与多档推理预算调节。

思考推理深度 (--thinking) level: high

四种形态与进程内嵌入

同一套 Rust 核心支持终端交互 REPL、单次 JSON Lines 事件流、双向 Stdio RPC 协议（支持实时 steer 注入与外部 MCP 桥接），也可直接通过 Host trait 零 IPC 链接进你的桌面或服务端宿主。

运行形态 (--mode / Host trait) mode: text

实测基准与资源边界

2.5 ms
CLI 冷启动中位耗时（hyperfine -N 实测），比 Node.js 与 Python 运行时编程 Agent 快两百倍以上，比 Codex CLI (9.0 ms) 快三倍半。
5.6 MB
单实例峰值常驻内存 (5,732 KB RSS)，仅为 TypeScript / V8 同类工具 (166.5 MB) 的三十分之一，可在低配云主机或嵌入式容器中常驻。
9.2 MB
一主代理加四路并发只读子代理同进程运行时的总内存峰值，进程内共享 Tokio 异步调度器与连接池，无需重复拉起外部子进程。
14 MB
Stripped 单文件二进制体积，基于 Rust 2024 Edition 构建，零外部虚拟机或脚本环境依赖。
180 tok
默认系统提示词基础开销（84 字极简指令），相比动辄数千 tokens 的黑盒提示词，节省 90% 以上基底开销并保护缓存命中率。

工程边界与问答

会话快照文件 (.mio/sessions/*.json) 会泄露我的 API 密钥吗？ 不会。Mio 在序列化会话快照时绝不写入 Config 中的连接密钥，并在 Unix 下强制设置 0600 权限。但对话历史本身包含读取过的代码片段与命令输出，请按项目敏感数据管理。

只读子代理 (read_only: true) 真的无法修改文件或执行命令吗？ 是的。在工具构建与执行双层拦截下，只读工作区既不向模型暴露也拒绝执行 write、edit 与 bash，且不能再次嵌套派生子代理；主代理施加的 --no-shell 也会自动约束所有子代理。

路径防越界检查等同于操作系统容器沙箱吗？ 不等同。checked_path 严格拦截绝对路径、.. 与符号链接穿透，但文件读写与默认 CLI Shell 仍以当前用户权限运行。生产多租户隔离请结合容器或实现自定义 Host::approve_tool 审批门控。

取消任务时子进程与已写入文件如何处理？ Unix 下取消任务会立即终止独立子进程组；丢弃异步 Future 不会自动回滚此前已落盘的文件修改。自定义实现 Host::shell 的宿主应用需自行负责子进程超时与回收。

如何在不破坏既有对话的前提下尝试另一种重构方案？ 运行 mio --resume --fork 或在交互模式输入 /fork，Mio 会将当前会话克隆到新的时间戳快照文件并在新分支上继续；也可在交互模式输入 /tree 回退到任意历史轮次。

主会话离线恢复后会重建运行中的子代理内存态吗？ 不会。SubagentManager 在进程内维护最多 128 个子会话（单会话上限 2 MiB），已完成的子代理结果已保存在主会话历史中，重启进程后可按需派生新的子代理。

如何接入外部 MCP 服务或复用 Antigravity 账号？ 在工作区放置 .mio/mcp.json（或 ~/.config/mio/mcp.json）即可通过 stdio JSON-RPC 2.0 自动注册 mcp__<server>__<tool>；运行 mio --import-antigravity ~/.pi/agent 即可一键导入本机凭证。

Mio 与 Rig、Ravomi 以及 Pi 是什么关系？ Mio 从 Ravomi 桌面应用中抽离为独立无头引擎，底层基于 Rig Rust LLM 框架构建（完整保留 MIT 许可与第三方致谢），并在极简上下文工程、会话树与思考档位上致敬了 Pi Coding Agent。

在终端以 2.5 毫秒启动它，或将 mio-agent 直接编译进你的下一个 Rust 应用。
