Mio Plugin Standard v1 · 两分钟构建并发布你的插件

SPECIFICATION.md ↗
1

脚手架生成标准骨架

使用 mio --plugin-init 自动生成包含 mio-plugin.json、SKILL.md、提示词模板与 CONTEXT.md 的合规目录：

bash
mio --plugin-init ./my-plugin mio --plugin-validate ./my-plugin
2

声明式配置 mio-plugin.json

无需编写复杂的胶水代码，只需声明 skills、prompts、mcp 与非交互式命令工具（自动暴露为 plugin__<name>__<tool>）：

mio-plugin.json
{ "schema_version": 1, "name": "my-plugin", "version": "0.1.0", "description": "Custom workflow plugin", "skills": ["skills"], "prompts": ["prompts"], "context_files": ["CONTEXT.md"], "tools": [] }
3

本地安装验证并提交至 GitHub

本地安装验证后，向 Ravomi/mio-plugins 提交 PR 或注册你的独立 GitHub 仓库，GitHub Actions 会自动校验合规性：

bash
# 本地或直接从 GitHub 仓库安装 mio --plugin-install ./my-plugin mio --plugin-install github:your-org/my-plugin
