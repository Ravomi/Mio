安装 Mio

选择适合你的终端或包管理器。当前公共二进制与 npm 包尚待首次发布；现阶段可从源码安装。

CURL
curl -fsSL https://raw.githubusercontent.com/Ravomi/Mio/main/docs/install.sh | bash
POWERSHELL
irm https://raw.githubusercontent.com/Ravomi/Mio/main/docs/install.ps1 | iex
NPM
npm install -g @ravomi/mio
PNPM
pnpm add -g @ravomi/mio
BUN
bun add -g @ravomi/mio
CARGO
git clone https://github.com/Ravomi/Mio.git
cd Mio
cargo install --path . --locked

平台与要求

平台支持情况
Linux x64 / ARM64glibc 发行版；预编译包基于 Ubuntu 24.04（glibc 2.39+），不支持 Alpine/musl。
macOS Intel / Apple Silicon原生二进制，默认安装到 ~/.local/bin。
Windows x64使用 PowerShell 安装；Windows ARM64 暂无预编译包。
npm / pnpm / Bun包装器需 Node.js 18+；首次运行下载并校验对应平台二进制。
CargoRust 1.95+，从源码构建。

安装后运行 mio --version 验证。使用 --model、MIO_MODEL 或已导入的 Antigravity 配置选择模型。
