配置凭据与提供商说明

• 环境变量凭据：在 API 密钥路由中，统一环境变量 MIO_API_KEY 拥有更高优先级；若未设定则依次读取提供商专属变量（如 OPENAI_API_KEY）。

• Antigravity 提供商：基于 Google Cloud Code PA 的 OAuth 机制运行，完全独立于标准 API Key，支持通过命令直接导入已有凭据：

mio --import-antigravity ~/.pi/agent

• 配置目录查找优先级：MIO_CONFIG_DIR > XDG_CONFIG_HOME/mio > ~/.config/mio。导入配置时亦可指定默认模型。

• 思考能力说明：仅在 Antigravity 适配器中启用且依赖具体账号权限，其他提供商按需选择对应思考型模型或通过网关透传。
